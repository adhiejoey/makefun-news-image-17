## The image

A newspaper front page, drawn entirely in code (no stock photos, no
copied artwork):

- **Masthead** — "THE WORLD IN ONE DAY", dated Tuesday, 17 November 2026.
- **Lead story** — NVIDIA smashes records: record quarterly revenue of
  $115.8 billion, beating forecasts, as its board refuses to reinstate
  ex-CEO Jensen Huang after his resignation in a spy scandal.
- **Six more stories across regions and fields**, each with its own
  pictogram, kicker and short summary:
  1. **US strikes Iran** — US jets hit Iranian missile sites after tanker
     attacks in the Strait of Hormuz; Iran drones a US radar base in Bahrain.
  2. **Kerch Bridge hit** — Ukrainian drones collapse a section of the
     Kerch Bridge to Crimea; Russia hits bridges in Kyiv in reply.
  3. **Trump's Asia trip** — a Quad summit in Manila, ahead of a three-way
     summit with Xi Jinping and Vladimir Putin in China.
  4. **Japan sends jets** — fighter jets scrambled after Russian aircraft
     enter Japanese airspace.
  5. **Gaza aid plea** — Britain, Australia, Canada and Italy urge Israel
     to open Gaza crossings as aid groups warn of catastrophe.
  6. **Measles returns** — the US loses its measles elimination status for
     the first time since 2000.
- **Footer briefs** — Depardieu admits assault, Tiger Woods returns to golf,
  Mongolia's president quits.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png — a 1024x1024 PNG, deterministic across runs
```

## How this entry was built

The program was written end to end in a recorded agent session: `main.py`
draws every pixel itself with the standard library (a small PNG encoder,
a bitmap font, geometric pictograms) — no image is copied in. The font
bitmaps in `fontdata.py` were extracted from the system DejaVu Sans Bold
font by `tools/make_font.py`.
